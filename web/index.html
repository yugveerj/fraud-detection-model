Fraud‑Scoring

A fraud-detection model built, validated, deployed, and monitored the way a bank's model-risk team would require. A frozen, dollar-optimized threshold turns each calibrated probability into review or approve; everything on this page is judged against that line — decision quality and validation rigor, not leaderboard AUC. Built end-to-end by one person: data pipeline, model, live scoring API on AWS, weekly drift monitoring, and the validation document.
