# Bundled fonts

Self-hosted (same-origin) so the demo works offline. All under the SIL Open Font
License 1.1 (OFL), which permits redistribution and web embedding.

- **IBM Plex Mono, IBM Plex Sans** — © IBM Corp. — https://github.com/IBM/plex — OFL-1.1
- **Archivo** — © Omnibus-Type — https://github.com/Omnibus-Type/Archivo — OFL-1.1

Only the Latin subset (`.woff2`) of each weight in use is bundled. Full license text: https://openfontlicense.org

- **Archivo (variable, wdth+wght axes)** — © Omnibus-Type — same OFL-1.1 source as above;
  `archivo-vf.woff2` (latin) powers the expanded display setting. The static 700/800 files
  are retained as the design's documented fallback.
